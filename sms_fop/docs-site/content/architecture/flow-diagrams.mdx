## 2. Transaction promotion — FOP to processed

FOP INSERTs into `staging.txn_inbox`. An AFTER INSERT trigger fires per row and drains synchronously into `processed.inv_transaction`. Reservation cascade happens automatically via the `f_stock_balance_txn_apply` trigger on the INSERT into `inv_transaction`.

```mermaid
%%{init: {"theme":"base","themeVariables":{"actorBkg":"#ccfbf1","actorBorder":"#0d9488","actorTextColor":"#134e4a","signalColor":"#334155","signalTextColor":"#334155","noteBkgColor":"#fef3c7","noteBorderColor":"#d97706","noteTextColor":"#78350f","activationBkgColor":"#e0e7ff","activationBorderColor":"#6366f1","labelBoxBkgColor":"#f1f5f9","labelBoxBorderColor":"#94a3b8","labelTextColor":"#1e293b","loopTextColor":"#1e293b","fontSize":"14px"}}}%%
sequenceDiagram
    autonumber
    participant FOP as FOP service
    participant TX as staging.txn_inbox
    participant PT as f_promote_txn trigger
    participant IT as processed.inv_transaction
    participant TA as f_stock_balance_txn_apply
    participant SB as processed.stock_balance
    participant RA as f_stock_balance_reservation_apply
    participant SL as processed.sfdc_order_line

    FOP->>TX: INSERT tenant, external_txn_id, payload
    TX->>PT: AFTER INSERT trigger
    activate PT
    PT->>PT: parse payload
    PT->>PT: lookup masters
    alt validation ok
        PT->>IT: INSERT inv_transaction
        IT->>TA: AFTER INSERT trigger
        TA->>SB: bump on_hand_qty by signed_qty
        alt outbound and matches erp_line_id
            IT->>RA: trigger cascades
            RA->>SL: bump shipped_qty by abs signed_qty
            alt shipped_qty at or above qty
                RA->>SL: line_state closed, fop_synced_at now
                RA->>SB: release residual reserved
            else partial
                RA->>SB: reduce reserved by abs signed_qty
            end
        end
        PT->>TX: status processed, processed_at now
    else validation fail
        PT->>TX: status rejected with reject_reason
        PT->>PT: notify_outbox warn promote_txn
    end
    deactivate PT
```

## 5. Observability event stream — audit.v_all_events
