Solution documentation for **`psql-inventory-integration-service`** — the Michelin on-premises inventory ledger.

A long-running Java 21 process that polls files.com or SFTP for `MICH_INV_STOCKLEVEL_*` files, decodes them against a YAML interface catalog, loads them into a Postgres 16 schema (`staging → processed`), and emits an audit trail plus webhook notifications. A companion PostgreSQL database owns the live ledger, the ATP calculation, the reservation cascade, and the read API.
